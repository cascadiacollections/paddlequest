# Assets

Every binary in this repository, where it came from, and what licence it
carries. A repository with unlabelled binaries in it is one nobody else can
safely reuse, and "free to download" is not the same thing as "free to
redistribute" - which is what a public git repository does.

## The rule

New third-party assets must be **CC0** or **CC-BY**, and nothing else.

- **CC0** - public domain. Commercial use, no attribution required. Preferred.
- **CC-BY** - attribution required. Allowed, but it must be recorded in the
  table below at the time it is added, not afterwards.
- **Not allowed:** NC (non-commercial) or SA (share-alike) terms, and the
  custom "free" licences used by TurboSquid, CGTrader, Free3D and CadNav.
  Most of those forbid redistribution, so committing one here breaks them.
  Sketchfab is mixed - its default upload licence is CC-BY, not CC0, so
  filter before downloading.

Sources that are reliably CC0: [Kenney](https://kenney.nl),
[Quaternius](https://quaternius.com), [Poly Haven](https://polyhaven.com),
[ambientCG](https://ambientcg.com). Freesound is mixed; filter to CC0.

### Note on `audio/bonk.wav`

Its provenance was never written down. The file itself is consistent with
having been generated rather than recorded or downloaded:

- a bare canonical 44-byte header with exactly two chunks (`fmt `, `data`)
  and no `LIST`/`INFO`/`ISFT` metadata at all, where a file from a sample
  pack or an audio editor almost always carries something
- a peak of exactly 32767, i.e. normalized precisely to full scale
- a clean monotonic decay envelope over its 0.12s, 44.1kHz mono

That is evidence, not proof. If it did come from somewhere, correct this row
before the project is distributed. If it was generated, consider committing
the generator next to `tools/make_paddle.py` so the sound is a diff too.
